# Сайт бронирования столиков — Soju & Seoul

## 📖 Описание проекта
Веб-приложение для бронирования столиков в ресторане *Soju & Seoul*.  
Проект реализован на фреймворке **Django** с использованием **Bootstrap** для создания адаптивного интерфейса и подключением к админке Django для управления бронированиями и контентом сайта.

---

## 🎯 Цели проекта
1. Сверстать сайт для бронирования столиков.  
2. Подключить сайт к админке Django.  
3. Использовать Bootstrap для адаптивного и современного интерфейса.

---

## ⚙️ Основной функционал

### Главная страница:
- Описание ресторана  
- Перечень услуг  
- Контактная информация  
- Форма обратной связи  

### Страница «О ресторане»:
- История ресторана  
- Миссия и ценности  
- Команда  

### Страница бронирования:
- Форма бронирования столика  
- Проверка доступности  
- Подтверждение бронирования  

### Личный кабинет:
- Регистрация и авторизация  
- Просмотр истории бронирований  
- Управление бронированиями (изменение, отмена)  

### Админка:
- Управление пользователями  
- Управление бронированиями  
- Управление контентом  

---

## 🧰 Технологии

- **Backend**: Django  
- **Frontend**: HTML, CSS, Bootstrap  
- **База данных**: PostgreSQL  
- **Контейнеризация**: Docker, Docker Compose  
- **Админ-панель**: Django Admin

## 🚀 Установка и запуск проекта

1. Клонировать репозиторий:
   \`\`\`bash
   git clone https://github.com/username/restaurant-booking.git
   cd restaurant-booking
   \`\`\`

2. Создать виртуальное окружение:
   \`\`\`bash
   python -m venv venv
   source venv/bin/activate   # для macOS/Linux
   venv\Scripts\activate      # для Windows
   \`\`\`

3. Установить зависимости:
   \`\`\`bash
   pip install -r requirements.txt
   \`\`\`

4. Запустить сервер разработки:
   \`\`\`bash
   python manage.py runserver
   \`\`\`

5. Открыть в браузере:
   [http://127.0.0.1:8000](http://127.0.0.1:8000)
